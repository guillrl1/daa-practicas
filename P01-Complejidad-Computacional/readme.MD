# Práctica 1: Análisis de Complejidad - DAA

Este proyecto implementa el producto de matrices utilizando el **Patrón Estrategia** y los principios **SOLID** en C#. Permite comparar el rendimiento entre el recorrido por filas y por columnas para analizar la complejidad $O(n^3)$ en el límite.

## Requisitos Previos

* **SDK de .NET 8.0** o superior instalado en el sistema.
* Contar con el archivo `Practica1.csproj` en la raíz del directorio para la gestión de dependencias y compilación.

## Instrucciones de Ejecución

Desde la terminal en la carpeta raíz del proyecto, ejecute los siguientes comandos:

### 1. Compilación y Generación de Binarios
